DSHub Build2Earn — College Football Fantasy

Overview

College Football Fantasy is a fantasy sports platform developed as part
of the DSHub Build2Earn program.

The platform enables users to create fantasy teams using college football
players, participate in gameweeks, join leagues, and compete through
points and leaderboards.
